# Personal Portfolio Website

## 📌 About the Project

This is a simple personal portfolio website created using HTML and basic CSS. The website showcases my introduction, 
skills, and projects in a clean and organized layout. 
This project helped me improve my understanding of HTML structure, CSS styling, and basic web design.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Simple and clean user interface
* Personal introduction section
* Skills and projects sections
* Basic CSS styling and layout
* Beginner-friendly and responsive design practice

## 🎯 Purpose

The main purpose of this project is to practice my front-end development skills and build a foundation for 
creating more advanced websites in the future.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your browser.
